# Upload to GitHub Pages

1. Open your GitHub repository.
2. Replace the old site files with the files from this release.
3. Make sure `index.html`, `style.css`, `script.js`, and `questions.js` are in the repository root.
4. Commit the changes.
5. In **Settings → Pages**, keep deployment set to your repository branch/root as before.
6. Refresh the GitHub Pages site after the deployment completes.

If replacing an existing version, a hard refresh may be needed because browsers can cache JavaScript/CSS.
